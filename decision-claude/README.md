# 記憶與腦健康決策工具（Claude Code 版）

繁體中文的失智症篩檢、風險預測、個人化預防衛教、診斷說明與治療決策網站。

- 線上位置：`https://a7662888.github.io/dementia-assessment/decision-claude/`
- 純靜態，無 build step、無後端、無追蹤。所有作答只存在使用者的瀏覽器分頁（`sessionStorage`），關閉分頁即清除。
- 這是**兩個並行版本中的其中一版**（另一版由 Codex 獨立實作）。目錄名稱刻意分開以免互相覆蓋；擇定之後再改名或提升到根目錄。

## 流程

```
首頁（含急症紅旗）
├─ 路徑一：目前沒有明顯認知困擾
│    └─ 風險評估（9 段問卷）→ 風險因子點數 → 個人化預防重點
└─ 路徑二：自覺記憶或思考變差
     └─ SCDS 第一部分 → SCDS 第二部分（14 題）→ SCD-plus 補充題
        → AD-8（家屬版）→ 整理結果
延伸
├─ 臨床診斷會做些什麼（連到本 repo 既有的臨床病史問卷與 MoCA-T）
└─ 生物標記與 ATT 醫病共享決策
```

## 這一版做了哪些判斷

### CogDrisk 的條件式規則是反推出來的

CogDrisk Short Form 的計分規則沒有公開（問卷 PDF 只有題目，且明訂使用與改作須向 UNSW 授權）。但 **Anstey 2022 是開放取用（CC BY-NC-ND），Table 1 有完整的 17 因子點數**，本站據此逐格實作。

原表在因子名稱後標註了年齡（例如「高血壓（>65 歲）」），但這些標註有兩種意義。以原文內文所述的分數範圍反推，可以確定：

| 因子 | 標註 | 實際處理 |
|---|---|---|
| 中年肥胖 | ≤65 歲 | **真的排除**，超過 65 歲不計分 |
| 高膽固醇 | <60 歲 | **真的排除**，60 歲以上不計分 |
| 高血壓 | >65 歲 | 只是效應量來源族群，**全年齡計分** |
| 心房顫動 | >65 歲 | 只是效應量來源族群，**全年齡計分** |

驗證（見 `test-scoring.js`）：

- 晚年上限 = 23+4+3+2+2+1+2+2+3+2+1 = **45**（原文：late-life 上限 45）
- 中年上限 = 4+3+3+3+2+2+1+2+2+3+2+1 = **28**（原文：midlife 上限 28）
- 中年下限 = −3−5−0.25 = **−8.25**（原文：midlife 下限 −8.25）

若把高血壓與心房顫動在 65 歲以下排除，中年上限只會得到 24，與原文不符。

**未能重現**：原文所述的 late-life 下限 −4.25。本站在 60–64 歲、保護因子全達標時得到 −8.25。原文的條件式方程式在 Supporting Information Part B，本站未取得。

### 不輸出風險百分比

原文沒有發表「幾點等於多少風險」的對照表，因此任何百分比都會是編造的。本站輸出點數、該年齡層的可得範圍，以及使用者在範圍中的位置。

既有的 `cogdrisk-tw` 站使用 CAIDE 輸出二十年風險百分比。Huque 2023（JAMA Netw Open）在三個高齡世代的比較顯示 CAIDE 的 AUC 最低到 0.50（MAP 世代，平均 80 歲），等同亂猜；CogDrisk 為 0.65–0.75。本站因此不對高齡使用者輸出 CAIDE 百分比。

### 三項操作化假設

原始權重的因子定義與本站實際問得到的資料不完全一致，介面上以標籤標示，並顯示假設造成的分數擺盪區間：

| 因子 | 論文定義 | 本站做法 |
|---|---|---|
| 失眠 | 臨床診斷之失眠症 | ISI ≥ 15 |
| 憂鬱 | CES-D（20 題版）> 20 | CES-D-10 ≥ 10 |
| 動腦活動 | 原始常模三分組 | 本題組 0–24 分三等分 |

### SCDS 不設切分點

Tsai 2021 原文明載切分點仍待縱貫研究驗證，且 SCD 組（32.86±9.53）與 MCI 組（32.73±9.34）分數幾乎相同。本站只呈現分數與三組平均的相對位置，不做判定。

三因子與最終 14 題的對應是**推定**的：原文 Table 3 用初版題號（#E-23 等）呈現，未直接對應最終題號。依題數（6/4/4）與因子內容描述，附錄題序恰為分因子連續排列，故推定 1–6 為執行功能與定向、7–10 為語言、11–14 為記憶。

### AD-8 是唯一有經驗證切分點的一份

≥2 分建議進一步檢查。題目文字依台南市政府衛生局與天主教失智老人基金會的公開版本逐字核對。

## 已知限制

1. CogDrisk 官方條件式方程式與加總常數未取得（Supporting Information Part B）。
2. 原文 late-life 下限 −4.25 未能重現。
3. ATT 模組的價格與仿單資訊查核日為 **2026-08-26**，需定期更新；查核日已顯示在介面上。
4. 聽力、視力、飲酒、空氣污染、社交次數只用於衛教建議，不計入點數——CogDrisk 的 any-dementia 演算法未納入這些因子。
5. SCDS 常模來自單一研究（N=175，55 歲以上），僅供粗略定位。
6. 本次開發環境無法擷取螢幕截圖，版面是以 DOM 結構、對比度計算與溢位量測驗證的，未做像素級目視確認。

## 開發

```bash
node test-scoring.js          # 計分自我檢驗（44 項）
py -3 -m http.server 8731     # 在 repo 根目錄啟動，開 /decision-claude/
```

修改權重或量表時，請一併更新 `test-scoring.js` 的對照，並確認 `data/prevention.js` 中 14 項 PAF 仍加總為 45。
