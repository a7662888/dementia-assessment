# 記憶與腦健康決策工具（Claude Code 版）

繁體中文的失智症篩檢、風險預測、個人化預防衛教、診斷說明與治療決策網站。

- 線上位置：`https://a7662888.github.io/dementia-assessment/decision-claude/`
- 純靜態，無 build step、無後端、無追蹤。所有作答只存在使用者的瀏覽器分頁（`sessionStorage`），關閉分頁即清除。
- 這是**兩個並行版本中的其中一版**（另一版由 Codex 獨立實作）。目錄名稱刻意分開以免互相覆蓋；擇定之後再改名或提升到根目錄。

## 流程

```
首頁（含急症紅旗）
├─ 路徑一：目前沒有明顯認知困擾
│    └─ 風險評估（9 段問卷）→ 風險因子點數 → 個人化預防重點
└─ 路徑二：自覺記憶或思考變差 → 選擇由誰填寫（三選一）
     ├─ 本人與家屬都填：SCDS 一 → SCDS 二 → 補充題 → AD-8 → 整理結果
     ├─ 只填本人：SCDS 一 → SCDS 二 → 補充題 → 整理結果
     └─ 只填家屬：AD-8 → 補充題（家屬版問法）→ 整理結果
延伸
├─ 臨床診斷會做些什麼（連到本 repo 既有的臨床病史問卷與 MoCA-T）
└─ 生物標記與 ATT 醫病共享決策
```

## 這一版做了哪些判斷

### CogDrisk 的條件式規則是反推出來的

CogDrisk Short Form 的計分規則沒有公開（問卷 PDF 只有題目，且明訂使用與改作須向 UNSW 授權）。但 **Anstey 2022 是開放取用（CC BY-NC-ND），Table 1 有完整的 17 因子點數**，本站據此逐格實作。

原表在因子名稱後標註了年齡（例如「高血壓（>65 歲）」），但這些標註有兩種意義。以原文內文所述的分數範圍反推，可以確定：

| 因子 | 標註 | 實際處理 |
|---|---|---|
| 中年肥胖 | ≤65 歲 | **真的排除**，超過 65 歲不計分 |
| 高膽固醇 | <60 歲 | **真的排除**，60 歲以上不計分 |
| 高血壓 | >65 歲 | 只是效應量來源族群，**全年齡計分** |
| 心房顫動 | >65 歲 | 只是效應量來源族群，**全年齡計分** |

驗證（見 `test-scoring.js`）：

- 晚年上限 = 23+4+3+2+2+1+2+2+3+2+1 = **45**（原文：late-life 上限 45）
- 中年上限 = 4+3+3+3+2+2+1+2+2+3+2+1 = **28**（原文：midlife 上限 28）
- 中年下限 = −3−5−0.25 = **−8.25**（原文：midlife 下限 −8.25）

若把高血壓與心房顫動在 65 歲以下排除，中年上限只會得到 24，與原文不符。

**未能重現**：原文所述的 late-life 下限 −4.25。本站在 60–64 歲、保護因子全達標時得到 −8.25。原文的條件式方程式在 Supporting Information Part B，本站未取得。

### 不輸出風險百分比

原文沒有發表「幾點等於多少風險」的對照表，因此任何百分比都會是編造的。本站輸出點數、該年齡層的可得範圍，以及使用者在範圍中的位置。

既有的 `cogdrisk-tw` 站使用 CAIDE 輸出二十年風險百分比。Huque 2023（JAMA Netw Open）在三個高齡世代的比較顯示 CAIDE 的 AUC 最低到 0.50（MAP 世代，平均 80 歲），等同亂猜；CogDrisk 為 0.65–0.75。本站因此不對高齡使用者輸出 CAIDE 百分比。

### 量測工具已確定，只剩切分點是假設

Kootar 2023 的補充資料 Part B（`Supplementary Information 1`，即 `1-s2.0-S2274580724002061-mmc1.docx`）逐項載明了 CogDrisk 各因子實際使用的量表，Anstey 2024 短版論文 Table 2 則提供了各分類的實際比例。兩者合起來把原本的假設收斂了不少：

**已確定，不再是假設**

| 因子 | 依據 |
|---|---|
| 憂鬱：CES-D-10 **≥ 8** | Kootar 2023 補充資料明載「CES-D（10 題版），切分點 8」。Anstey 2022 Table 1 寫的「CES-D > 20」指的是效應量來源所用的 20 題版；10 題版的 8 分約當 20 題版的 16 分。Anstey 2024 樣本中 33.1% 達標，與此一致。 |
| 失眠採 ISI、孤獨感採三題版 UCLA、身體活動採 IPAQ 短版、動腦活動改編自 MAP 世代題目 | Kootar 2023 補充資料 Part B 之 CogDrisk 欄位 |

**仍是假設（工具確定，切分點未發表）**

| 因子 | 本站做法 | 校準依據與偏誤方向 |
|---|---|---|
| 失眠 | ISI ≥ 8 | Anstey 2024 樣本中 43.4% 被歸為失眠。臨床顯著的 ≥15 在社群樣本通常只有一成上下，與 43.4% 不符，故採 ≥8。 |
| 孤獨感 | UCLA-3 ≥ 6（滿分 9） | ≥6 是最常引用的切分點，但該樣本有 65.4% 被歸為孤獨，顯示 CogDrisk 實際門檻可能更寬鬆。本站這一項**偏保守，可能少算 2 分**。 |
| 動腦活動 | 本題組 0–24 分，以 ≤16／17–21／≥22 分組 | 原本的等分三分法是錯的。該樣本實際分布為最低組 88.4%、中間組 10.8%、最高組 0.8%，等分三分會讓遠超過一成的人拿到 −5 分。本站把門檻拉高以貼近已發表的分布。 |

### 社群參考分布

結果頁會顯示使用者的分數在真實人群中的相對位置：Anstey 2024 的澳洲線上社群樣本（n=647，40–89 歲，平均 62.2 歲，50.1% 女性）CogDrisk 短版分數平均 9.7（SD 5.3），實際落在 −2.6 到 27.9。

這**不是台灣常模**，也不是疾病風險分級；百分位以常態近似換算，原始分數不必然常態。介面上都有標示。

### SCDS 不設切分點

Tsai 2021 原文明載切分點仍待縱貫研究驗證，且 SCD 組（32.86±9.53）與 MCI 組（32.73±9.34）分數幾乎相同。本站只呈現分數與三組平均的相對位置，不做判定。

三因子與最終 14 題的對應是**推定**的：原文 Table 3 用初版題號（#E-23 等）呈現，未直接對應最終題號。依題數（6/4/4）與因子內容描述，附錄題序恰為分因子連續排列，故推定 1–6 為執行功能與定向、7–10 為語言、11–14 為記憶。

### AD-8 是唯一有經驗證切分點的一份

≥2 分建議進一步檢查。題目文字依台南市政府衛生局與天主教失智老人基金會的公開版本逐字核對。

### 自填與家屬填可以二擇一

主觀認知減退路徑先問「這次由誰填寫」，三選一：本人與家屬都填／只填本人／只填家屬。步驟序列、進度條、上一步下一步都依此動態產生。

關鍵設計：**資料缺漏一律標為「資料不足」，絕不當成「沒有這個特徵」**，否則只填一邊的人會被系統性低估。結果頁會說明哪幾項因此無法判定、原因是什麼，並提供一鍵補填另一份。「建議下一步」的判斷除了絕對項數，也看「可判定項目中的比例」，避免因為少填一份而被低估。

只填本人 → 「親近家人是否也觀察到」無法判定（1 項）。
只填家屬 → 「對此感到擔心」「覺得比同齡差」「曾因此求助」無法判定（3 項）。

## 已知限制

1. CogDrisk 官方的條件式方程式與加總常數未取得——那是 **Anstey 2022 的** Supporting Information Part B，與本站已取得的 Kootar 2023 補充資料 Part B（變數操作化）是不同的文件。
2. 原文 late-life 下限 −4.25 未能重現。
3. 失眠與孤獨感的切分點仍是依已發表比例反推的假設，不是原文明載值。
4. ATT 模組的價格與仿單資訊查核日為 **2026-08-26**，需定期更新；查核日已顯示在介面上。
5. 聽力、視力、飲酒、空氣污染、社交次數只用於衛教建議，不計入點數——CogDrisk 的 any-dementia 演算法未納入這些因子。
6. SCDS 常模來自單一研究（N=175，55 歲以上），僅供粗略定位。
7. 本次開發環境無法擷取螢幕截圖，版面是以 DOM 結構、對比度計算與溢位量測驗證的，未做像素級目視確認。
